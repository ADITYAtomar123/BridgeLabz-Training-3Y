CSS Box Model

The CSS box model describes how every HTML element is made up of content, padding, border, and margin.

Content

This is the content area of the box.

Content

The content is the actual text or information inside an element.

Padding

Padding is the space between the content and the border.

Border

Border surrounds the padding and content area.

Margin

Margin is the space outside the border that separates elements.
