Responsive CSS Cheat Sheet

Filters

CSS filters can change the appearance of images. Example: filter: grayscale(100%);

Media Queries

Media queries apply different styles for different screen sizes. Example: @media (max-width: 700px)

Responsive Design

Responsive design makes a website adapt to different devices and screen sizes.

Typography

Use relative units and clamp() to create responsive text. Example: font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

Flexbox is used to arrange elements in rows or columns. Example: display: flex;

CSS Grid

Grid creates rows and columns for structured layouts. Example: display: grid;
