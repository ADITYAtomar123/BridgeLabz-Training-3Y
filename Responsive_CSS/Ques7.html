Responsive Design

Responsive web design allows a website to adjust automatically according to the screen size. CSS Flexbox, Grid and Media Queries help create layouts that work on desktops, tablets and mobile devices.

CSS Cheat Sheet

Flexbox

Used to arrange elements in rows or columns.

Grid

Used to create rows and columns.

Media Query

Changes styles for different screen sizes.
