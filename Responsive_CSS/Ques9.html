Responsive Design Principles

Fluid Layouts

Fluid layouts use flexible widths so that content adjusts according to the screen size. 

.container {
    width: 90%;
    margin: auto;
}

Flexible Media

Flexible media allows images and videos to resize automatically according to the screen size. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints change the layout at specific screen sizes to make the website responsive. 

@media (max-width: 600px) {
    .box {
        width: 100%;
    }
}
