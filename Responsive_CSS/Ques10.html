Responsive Design Concepts

Filters

CSS filters can change the appearance of images using effects like blur, grayscale, brightness and contrast.

filter: grayscale(100%);

Typography

Responsive typography makes text easy to read on different screen sizes.

font-size: 1.2rem;

Media Queries

Media queries allow CSS styles to change according to the screen size.

@media (max-width: 750px)
